Welcome to the new Aksara. This site has been completely rebuilt using [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com).

The previous version was built with Gatsby back in 2018. A lot has changed since then — both in the web ecosystem and in my life. This fresh start felt right.

## What's new

- **Faster builds** — Astro ships zero JavaScript by default
- **Dark mode** — toggle between light and dark themes
- **Better typography** — still focused on readability, powered by Tailwind's typography plugin
- **RSS feed** — subscribe at `/rss.xml`

More posts coming soon. Stay tuned.
